🌍 AI Travel Agent
📖 Overview

AI Travel Agent is a smart travel planning web application built using HTML, CSS, and JavaScript. It helps users generate personalized travel plans based on their source city, destination, budget, travel dates, and travel preferences.

The application provides AI-style travel recommendations, hotel suggestions, budget analysis, tourist attractions, voice input, dark mode, trip history, and frequently asked travel questions.
